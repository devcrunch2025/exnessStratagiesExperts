Anti-Churn & Broker Safety Rules (V7002 Core Guard)

  • Profit Ratchet Floor (V7002): An order will NEVER be modified if the proposed new SL locks LESS profit than the current SL (e.g., if an order already has $1.00 locked, any method proposing a $0.70 lock is immediately rejected). For BUY orders, SL can never move downward; for SELL orders, SL can never move upward.
  • Minimum $10 SL Improvement: If an order already has an active SL, it will not be modified unless the new SL improves by at least $10.0 raw BTC. This stops micro-modifications from flooding the server.
  • Minimum $15 Live Price Gap: The proposed SL must stay at least $15 (or broker stop level) away from the live Bid/Ask to avoid broker rejection (Error 130).

🛡️ Recovery Orders Strategy & Big Gap Protection

🚀 Opening Engine: When Recovery Orders Open
  • Big Adverse Gap Requirement: The live price must have pulled back at least RecoveryMinDistanceRaw = 2000 raw BTC points away from the parent order's open price.
  • Parent Loss Threshold: The parent trade's floating loss must reach dynamicRecoveryLossLimit <= -$1.00.
  • Direction Resumption Confirmation:
    • For BUY Parent: GlobalSSLDirection == 1 || EMADirection == 1
    • For SELL Parent: GlobalSSLDirection == -1 || EMADirection == -1
  • Weak EMA Filter Removed: The former restrictive pullback filter (!IsEmaWEAKDistanceReduced50PercentFromPeak()) was completely removed, allowing reliable entry whenever price gaps out into confirmed direction.
  • Lot Size Multiplier: Recovery order opens with parentLots * RecoveryLotMultiplier (2.0x volume) with comment RECOVERY_<ParentTicket>.
  • Order Throttling: Strictly respects MaxRecoveryOrders = 10 and maximum 1 order per candle.
💰 Exit Engine: Two Clear Exit Rules
  • Rule 1: Active Parent Pair (Combined Basket Exit >= $1.00):
    As long as the parent order is open and exists, the recovery order will NEVER close alone. The recovery order stays bound to the parent trade until their combined net profit (RecoveryProfit + ParentProfit) reaches >= $1.00 (RecoveryBasketProfitUSD). When reached, BOTH trades close together, completely eliminating the parent's loss and banking profit!
  • Rule 2: Clean Orphan Exit (>= $1.00 with Parent Closed):
    If the parent was closed previously (via Stop Loss, manual close, or basket exit), the recovery order becomes an orphan. Once recoveryProfit >= $1.00, the EA closes the orphan cleanly at market without attempting to close the non-existent parent order (eliminating error logs).
